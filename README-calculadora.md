# Calculadora em C

## Descrição do Projeto:

Este projeto foi desenvolvido para a atividade prática da disciplina **Desenvolvimento de Algoritmos e Pensamento Computacional**. A calculadora permite realizar 20 operações matemáticas por meio de um menu interativo no terminal.

## Objetivo:

Aplicar conceitos fundamentais da linguagem C, como variáveis, operadores matemáticos, estruturas condicionais, estruturas de repetição e bibliotecas.

## Funcionalidades:

A calculadora possui 20 operações:

1. Soma
2. Subtração
3. Multiplicação
4. Divisão
5. Resto da divisão
6. Potenciação
7. Raiz quadrada
8. Porcentagem
9. Média de dois números
10. Média de três números
11. Dobro
12. Triplo
13. Quadrado
14. Cubo
15. Identificação de número positivo, negativo ou zero
16. Maior entre dois números
17. Menor entre dois números
18. Valor absoluto
19. Seno
20. Cosseno

O programa também permite realizar várias operações consecutivas e encerrar a execução pela opção `0`.

## Tecnologias e Bibliotecas implementadas:

- **C:** linguagem utilizada no desenvolvimento.
- **`stdio.h`:** entrada e saída de dados com `scanf()` e `printf()`.
- **`math.h`:** cálculos matemáticos com `pow()`, `sqrt()`, `fabs()`, `sin()` e `cos()`.
- **GCC:** compilador utilizado para executar o programa.
- **GitHub:** armazenamento e compartilhamento do projeto.

## Conceitos Aplicados:

- **Variáveis:** armazenamento de números, resultados e opções.
- **Condicionais:** `if`, `else if` e `else` para verificar condições.
- **`switch...case`:** seleção das operações.
- **`do...while`:** repetição do menu até o encerramento.
- **Entrada e saída:** utilização de `scanf()` e `printf()`.
- **Tratamento de erros:** verificação de divisão por zero, raiz quadrada de número negativo e opções inválidas.

As operações estão organizadas em blocos dentro da função `main()`.


## Como Compilar e Executar?

1. Acesse o [OnlineGDB](https://www.onlinegdb.com/online_c_compiler).
2. Selecione a linguagem **C**.
3. Copie o código do arquivo `calculadora.c` e cole no editor.
4. Clique em **Run** para executar o programa.
5. Digite a opção desejada no console e informe os valores solicitados.

O menu permite realizar diferentes operações matemáticas até que o usuário escolha a opção `0` para encerrar o programa.
